# Scheduling & Communications

Appointment scheduling/dispatch, and every channel a company talks to leads through: SMS, voice calls, CallRail call-tracking, and inbound lead email.

| Feature | Status | Description | Code |
|---|---|---|---|
| Schedule (list view) | shipped | Server-rendered list of appointments/events for the company, with linked leads, jobs, reps, pipeline stages, tasks, notes, estimates, and calendars all preloaded; supports dispatch-scoped viewers who can only see reps/leads behind their own appointments. | `src/app/(app)/schedule/page.tsx`, `schedule-list.tsx`, `appointment-wizard.tsx` |
| Calendar (board view) | shipped | Same underlying data as Schedule but rendered as a calendar board; computes which reps are "on calendar" vs. active, and a narrower rep filter (Sales role OR already booked) so the assignment dropdown isn't cluttered with non-field staff. | `src/app/(app)/calendar/page.tsx`, `calendar-board.tsx`, `event-form.tsx`, `dispatcher-picker.tsx`, `visit-media.tsx`, `event-owner-note.tsx` |
| Appointment reports | shipped | Date-ranged (7/30/90/all) report of appointment outcomes per rep — attended vs. overdue-without-a-logged-result, with CSV export. | `src/app/(app)/appointment-reports/` |
| Appointment SMS notification settings | shipped | Per-company quick-text templates (confirm, reschedule, on-my-way, running-late) and a rep-info template, with a live SMS segment/cost meter that flags non-GSM characters (emoji, em dash) that silently double the segment count. | `src/app/(app)/settings/appointment-notifications/`, `src/lib/sms-segments.ts` |
| Calendars admin | shipped | CRUD + ordering for the named "calendars" appointments can be filed under (e.g. separate crews/branches). | `src/app/(app)/settings/calendars/` |
| Appointment reminder cron | shipped | Cron job texts leads 2–20 hours ahead of an appointment with time + map link. | `src/app/api/cron/appointment-reminders/` |
| No-show follow-up cron | shipped | If an appointment in "Appointment Scheduled" stage has no logged result by 8pm local company time, auto-moves the lead to a follow-up stage; only ever moves leads out of that one stage, so a lead already advanced to Proposal Sent/Won is left alone. | `src/app/api/cron/no-show-followups/` |
| Task reminder cron | shipped | Texts the assigned rep ~2 hours before a lead task's due time. | `src/app/api/cron/task-reminders/` |
| Rain-alert cron | shipped | Thrice-daily check of NWS forecast for any appointment/project within a 48h lookahead; texts a warning if probability-of-precipitation crosses 50%. Same rain-check logic backs an on-demand "Check rain now" button on the Projects page. | `src/app/api/cron/rain-alerts/`, `src/lib/rain-alerts-core.ts`, `src/lib/weather-provider.ts` |
| Call reports | shipped | Searchable/filterable (rep, disposition, date range incl. custom) log of calls with duration and disposition, editable inline. | `src/app/(app)/call-reports/` |
| Text (SMS) reports | shipped | Log of inbound/outbound SMS per lead, matched to a lead by phone number when no lead_id is set; flags inbound replies that read as an appointment yes/no confirmation. | `src/app/(app)/text-reports/` |
| Call scripts | shipped | Single free-text call script per company, editable by admins. | `src/app/(app)/settings/call-scripts/` |
| Call dispositions | shipped | Admin-managed, ordered, colored list of call outcome labels, each with rules (e.g. which stage-move it triggers). | `src/app/(app)/settings/call-dispositions/` |
| Phone numbers | shipped | Lists the company's Twilio numbers (synced from Twilio), lets admin set a label and a default send-from number, or remove one. | `src/app/(app)/settings/phone-numbers/`, `src/lib/actions/phone-numbers.ts` |
| Twilio account settings | shipped | Per-company Twilio account/number configuration (the number this company texts/calls from). | `src/app/(app)/settings/twilio/`, `src/lib/twilio-env.ts`, `src/lib/twilio-company.ts` |
| CallRail integration | shipped | Per-company CallRail account link for call tracking (which ad/keyword drove a call); webhook + backfill sync creates/matches leads from CallRail call data. | `src/app/(app)/settings/callrail/`, `src/app/api/callrail/webhook/`, `src/app/api/cron/callrail-backfill/`, `src/lib/callrail-sync.ts`, `src/lib/callrail-company.ts` |
| Inbound lead email | shipped | A forwarded lead-source email (Home Depot Pro Referral, Angi, Yelp, HomeAdvisor, Yelp, Thumbtack, Houzz, Facebook, Google, Nextdoor, answering services) is parsed — unwrapping the real original sender from auto-forwarded mail — into a new lead. | `src/app/(app)/settings/inbound-email/`, `src/app/api/email/inbound/`, `src/lib/inbound-email.ts` |
| Email sender settings | shipped | Per-company "from" address estimates/portal links are sent from. | `src/app/(app)/settings/email/`, `src/lib/email-env.ts`, `src/lib/email-company.ts` |
| Inbound/outbound voice calling | shipped | Twilio-signature-validated inbound call handling (TwiML), recording, and a recording-heard notice; call SID → lead matched by phone number. | `src/app/api/voice/*`, `src/lib/twilio-env.ts` |
| AI call transcription | shipped | Twilio Voice Intelligence turns a call recording into a transcript, kept entirely inside each company's own Twilio account (audio never leaves Twilio, billing stays on the company). | `src/lib/voice-intelligence.ts`, `src/app/api/voice/transcript-ready/` |
| AI call notes | shipped | Claude (Anthropic SDK) turns a finished call transcript into a short CRM note (project, details, objections, next step) once transcription completes; returns a sentinel `NO_NOTE` for calls too short to summarize. | `src/lib/ai-call-notes.ts` |
| SMS webhook (inbound/status) | shipped | Signature-validated inbound SMS handling that matches yes/no-style replies to pending appointment confirmations and updates the event; also handles Twilio delivery status callbacks. | `src/app/api/sms/webhook/`, `src/app/api/sms/status/`, `src/lib/events/confirmation.ts` |
