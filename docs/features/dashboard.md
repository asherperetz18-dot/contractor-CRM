# Dashboard

The overview page ("Dashboard 2.0"): headline numbers, graphs and a needs-attention strip, all following one date filter, with the boxes drag-arrangeable per person. It renders on every screen size — phones and portrait tablets get the same content reflowed (2-across cards, self-scrolling tables and chart, ≤700/≤1100 rules), with the Modules tile launcher appended below on tablets (701–900px); the old phone-only widget list (tasks/calls/week/month) is gone since the dashboard itself shows all of that now. See `.claude/skills/responsive-check` — the standing rule this set.

**Phone Home — Today (DECISIONS #090).** At phone width (≤700px, including the Android app) `/` opens on a short Today screen instead: the date, quick buttons (New contact, Appointment, Estimate, Clock in — only the pages the person can open), Needs attention (the dashboard's own alert rows: overdue tasks, overdue payments, awaiting signature, replies waiting, appointments today — money rows only for people with financials), Next up (the next three appointments, naming the client, tap to open the contact, Navigate to the address), and This month (new leads and appointments against last month). The full dashboard is one tap below it ("Show the full dashboard"), without the Modules tiles, which the More sheet replaces. Files: `src/lib/phone-today.ts` (+ `.test.ts`), `src/app/(app)/phone-today.tsx`, `src/app/(app)/page.tsx`, `src/app/globals.css`.

## Dispatch Dashboard

The desk's own overview at `/dispatch-dashboard`, its own top-level sidebar link right under Dashboard (so Settings › Menu Order can place it; it is not a row inside the Dispatch group) and on by default for the Dispatch role (Role Visibility can give it to anyone). It answers one question — is every lead being worked fast, and is the calendar filling — so it carries speed and the board, never money.

## Daily Brief

The 📈 button in the top bar (the More sheet on phones), opening on its own once a day for admins. Admin-gated in the server action, not just the button.

| Feature | Status | Description | Code |
|---|---|---|---|
| Needs attention | shipped | Always live, whatever period is picked: overdue tasks (not on closed leads), unconfirmed appointments in the next 2 days, refund requests open 30+ days, outdoor appointments this week with rain in the forecast. Each line links to the page that lists them. | `src/lib/actions/daily-brief.ts`, `src/app/(app)/daily-brief.tsx` |
| Today / This Week / This Month | shipped | One chip row drives everything below it: the eight number tiles (leads added — real leads only, DECISIONS #156 — appointments booked and scheduled, showed / no-show, calls and talk time, texts out / in, tasks completed, won and its value) and the two tables, Where Leads Came From (top 5 sources) and Rep Activity (top 6 reps by appointments booked plus calls). Today runs from midnight on the company's clock (until v1.244.0 it was the last 24 hours, so in the morning it held most of yesterday and its appointments ran from yesterday's date); This Week and This Month are rolling, the last 7 and 30 days. Calls and texts are read for the last 30 days only (no period looks further back), paged past the 1000-row cap; until v1.243.2 they were one bare select, so past 1000 of either the counts came from whichever 1000 rows came back. | `src/lib/daily-brief.ts` (+ `.test.ts`), `src/lib/actions/daily-brief.ts`, `src/app/(app)/daily-brief.tsx` |
